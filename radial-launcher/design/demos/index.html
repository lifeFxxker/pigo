DEMO C

浅色毛玻璃 Frost Light

同一套结构换浅色主题：中性浅灰壁纸 + 白瓷玻璃。适合白天 / 浅色壁纸，可作随系统主题切换的另一态。

blur 20px · tint 252 252 254 / 38-55%
hairline rgba(15,23,42,.10)
交互（A/B/C 一致）：按住 左键 / 中键 / 右键 在光标处呼出 —— 此时只有内环 4 分类；悬停某个分类，圆盘长大、对应外环飞出；移入外环选择条目；松开 执行，Esc 取消。右下角可切换三张中性壁纸。
关于落地：Demo 即视觉规格书 —— 玻璃配方（着色 / 模糊 / 高光 / 折射）与动效曲线（cubic-bezier(.32,.72,0,1)）将原样翻译进 Rust 渲染管线；当前 GDI 点阵方案需换 GPU 合成（wgpu / Direct2D + DirectComposition）才能实现实时毛玻璃与折射。
