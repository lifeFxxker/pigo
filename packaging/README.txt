PiPie —— Windows 光标径向启动器

单文件、零依赖的原生 Windows 可执行程序。按住鼠标侧键在光标处呼出轮盘，
把常用应用钉在内环，悬停应用即在其身侧展开该应用的窗口，并显示实时窗口预览。

快速使用
--------
· 呼出：按住鼠标侧键，轮盘在光标处弹出。松开启动高亮的应用；
        按 Esc 或任意其它键取消。也可在设置中改为中键、长按右键或自定义组合键。
· 固定应用：把快捷方式、.exe、文件夹或文件拖到内环磁贴上。
· 添加窗口：把一个窗口拖到轮盘上，归到它所属的应用下，之后会出现在该应用的外环。
· 预览：悬停应用展开它的窗口；悬停窗口胶囊显示实时预览。
· 设置：从托盘图标打开（右键 → 设置…）。

数据位置
--------
配置位于 %APPDATA%\PiPie\settings.ini，首次运行自动创建，通常通过应用内设置页编辑即可。
日志写入 %LOCALAPPDATA%\PiPie\logs\。
从旧版 Pigo 升级时，旧的 %APPDATA%\pigo\settings.ini 会在首次启动时自动复制过来。
